# Resilient Home 2040

A six-round household sustainability serious game. The student interface, lecturer dashboard and rules-based simulation are implemented in `index.html`, `style.css` and `game.js`.

## Running
Open `index.html` in a modern browser. No build tools are required.

## Classroom limitation
This version runs locally in one browser. Separate student devices do not synchronise; live classroom deployment requires a shared backend.

See the full README in the project package for workshop guidance.
